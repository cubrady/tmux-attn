## Project icons

The `project-*.svg` technology marks (Android, React/React Native, Next.js, Vue, Nuxt, Svelte, Angular, Flutter, Python, Rust, and Go) are from [Devicon](https://github.com/devicons/devicon/tree/master/icons) (upstream commit `32fe1d3b3f36ad11f90ab94f7db59738139c2bf6`; MIT; upstream license in `DEVICON-LICENSE.txt`). Brand marks remain the property of their owners. `project-cli.svg` is an original terminal symbol.

Icons describe confidently detected local project manifests, not agent tasks. Mixed workspace roots and unknown projects have no icon. Each peer detects its own directories; older peers without this metadata remain unlabelled.
